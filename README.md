# Sokoban

A Java implementation of the Sokoban puzzle game built with JSFML.
Level data is stored in Tiled TMX format.

## Quick start

Windows:

```bat
.\run.bat
```

Linux/macOS:

```bash
chmod +x run.sh build.sh
./run.sh
```

## Build

Windows:

```bat
build.bat
```

Linux/macOS:

```bash
./build.sh
```

The build output is written to `build/classes`.

## Controls

- Arrow keys - move and push boxes.
- Close the window - quit.
